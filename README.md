# Labyrint med tyngdekraft

Et minimalistisk 2D-fysikpuslespil bygget med HTML5 Canvas.

## Sådan spilles

1. Åbn `index.html` i din browser.
2. Brug venstre og højre piletast til at dreje hele banen 90°.
3. Hjælp den gule bold ud af labyrinten uden at falde i huller.

Spillet tæller din gennemførselstid, viser hurtigste niveau, og giver mulighed for at starte forfra med `R`.
